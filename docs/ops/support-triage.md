# Support triage

Status: Current

1. Acknowledge within the published support target.
2. Collect only release SHA, project ID, station/stage, request/job ID, and
   error category. Never request manuscript text, prompts, passwords, tokens,
   provider payloads, or signed URLs.
3. Check release identity, project ownership, job state, credit reservation,
   provider status, and the matching request ID in logs/Sentry.
4. Classify: billing, provider refusal/quota, generation failure, export,
   account access, abuse/legal, or security.
5. Follow the matching runbook and record operator minutes plus outcome.
6. Escalate immediately for cross-user access, billing mismatch, unrecoverable
   project loss, or suspected credential/content exposure.

Exercise this runbook with a synthetic request before serving the cohort and
link the result from the release evidence.
