# Slice 00 Implementation Handoff

Date: 2026-07-10

## Contract delivered

- `novel_to_comic.image_models.ImageRoute` is the stable application route enum:
  `GEMINI_FLASH_LITE`, `REVE`, `GPT_IMAGE_2`, and `UNKNOWN`.
- `novel_to_comic.image_models.ImageModelDescription` carries truthful
  `route`, `display_name`, and `provider_model` metadata.
- `novel_to_comic.image_models.describe_image_model(model)` is the route-description
  seam. Its production mappings agree with `litellm/config.yaml`:
  - `image-fast` and `image-balanced` ->
    `vertex-multimodal/gemini-3.1-flash-lite-image` / `GEMINI_FLASH_LITE`.
  - `image-quality` and `image-reve` -> `reve/create` / `REVE`.
  - Literal `gpt-image-2` and `openai/gpt-image-2` -> `GPT_IMAGE_2`.
  - Literal `reve/*` -> `REVE`.
- `is_reve_model()` and `is_gpt_image_2()` delegate classification to that seam.
- `config_for_image_model_alias()` stores a private, in-memory one-shot alias on
  its copied `Config`. Image-model precedence is now: one-shot alias, then
  existing dev-mode behavior, then `quality_preset`, then the configured field.
  The source/persisted project config is not mutated.
- Manual rerender, instructed rerender, and credit-estimate callers use the
  validated one-shot override path. No schema or version value changed.
