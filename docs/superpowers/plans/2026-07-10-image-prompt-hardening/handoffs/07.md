# Slice 07 Implementation Handoff

Date: 2026-07-11

## Contract delivered

- `provider_wire.PROVIDER_WIRE_SCHEMA_VERSION = 1` and discriminator
  `canary.provider-wire/1` define the portable JSON contract.
- `compile_provider_wire_request(CompiledGenerationRequest)` produces exact
  provider prompt parts, ordered semantic reference entries, bindings,
  dimensions, native aspect, approved controls, the compiled-request link, and
  `execution_fingerprint`.
- The fingerprint hashes every provider-affecting field and selected digest;
  local source paths and diagnostics are excluded.
- Reve positional syntax (`<img>N</img>`) is compiled from the same selected
  sequence as multipart order and numeric provider bindings.
- `materialize_wire_references()` and isolated-handler
  `verify_wire_images()` hard-fail on missing, unreadable, reordered, or
  digest-mismatched selected bytes before network I/O.
- `ai.generate_wire_image()` is the reachable schema-isolated entry point. It
  calls `LitellmHttpProvider.generate_wire()`; legacy `generate()` remains a
  separately documented deprecated raw branch until Slices 11–12.
- Isolated handlers use `litellm_handlers/provider_wire.py`, which imports no
  application packages. Vertex and Reve wire branches parse/verify/serialize;
  they do not author semantic prose, infer roles, cap/sort, or truncate.
- Vertex maps approved `quality` to native `ImageConfig.image_size`. Reve wire
  branches suppress unsupported legacy controls. Zero-reference generation and
  referenced edit requests both parse the manifest.
- `ProviderRawResult.actual_provider_model` records observed response identity
  separately from requested/configured identities; finalisation logs it.
- `labs.storage.stage_provider_wire_request()` stages bytes with the complete
  semantic wire manifest and unchanged execution identity.
