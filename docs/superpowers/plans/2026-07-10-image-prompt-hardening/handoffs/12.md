## Contract delivered

- Added panel-free `GenerationPromptInput` and explicit non-panel input types:
  `AbstractStyleProofInput`, `EntityStyleProofInput`,
  `CanonicalCharacterReferenceInput`, `CanonicalLocationPlateInput`,
  `CharacterStateReferenceInput`, `LocationStatePlateInput`,
  `PropReferenceInput`, and `ProjectCoverInput`.
- Extended `compile_generation_request` to accept panel-free inputs while
  preserving explicit verified asset geometry. Non-panel requests do not invent
  `scene_id` or `panel_number`.
- Added `non_panel_generation` as the common lifecycle owner:
  `compile_non_panel_request`, `estimate_non_panel_request`,
  `submit_non_panel_request`, `reference_plan_for_assets`,
  `style_reference_plan`, `asset_matches_request`, and
  `persist_non_panel_provenance`.
- Migrated style proofs, canonical character sheets, canonical location plates,
  conditioned character/location state assets, prop refs, and project covers to
  compiler → provider wire → frozen request → transport. Cache identity uses
  the compiled execution fingerprint; retries prepare a new request.
- Migrated Labs LiteLLM/Reve paths to consume explicit compiled provider wires;
  filename-based role inference and the direct Reve HTTP adapter were removed.
- Added `image_provenance.common_image_provenance` with schema version `1`.
  The envelope records asset kind/identity, prompt/compiled/wire/frozen
  versions, request and execution identities, selected/dropped refs and
  digests, configured/actual model identity, requested/effective/actual
  dimensions, controls, provider request id, cost, failure, timing, warnings,
  lineage extensions, and a timestamp-independent record hash.
- Panel provenance now delegates to the same common envelope. Conditioned state
  metadata retains its top-level lineage fields plus the common `lineage`
  extension, including canonical parent/style hashes and reference diagnostics.
- Style proofs have explicit abstract/entity anchor behavior. Supplied
  structured anchors remain protected verbatim; abstract inputs have no
  invented protected entity anchor. Style geometry is `(819, 1024)` and
  location geometry is `(1344, 768)` for both compiled requests and estimates.
- `LEGACY_IMAGE_CALLER_INVENTORY` is empty. The obsolete `clients/flux.py`
  wrapper and direct Reve adapter were removed; no production stage, route, or
  targeted Labs caller invokes raw prompt/path transport.
- Generic asset restore continues to reactivate archived image bytes and its
  archived metadata/provenance, with existing canonical/state lineage
  revalidation routes; it does not compile, freeze, enqueue, reserve, or call a
  provider.

## Behavior and deliberate deviations

- Existing outer generation-job wrappers for style/cast/cover routes remain;
  the actual image request is frozen and executed through the shared lifecycle
  inside the job. Stage-owned generation paths freeze before direct transport.
- `ai.client.generate_image` and legacy provider `generate` implementations
  remain reachable for existing low-level unit/provider compatibility, but no
  production stage, route, or migrated Labs caller references them and the
  reviewed non-panel inventory is empty. Full removal of that unused low-level
  compatibility surface is left to the later legacy-removal slice.
- Labs experimental cells use the common compiled-wire/provenance path but do
  not use project credited-job reservations; they retain the existing Labs cost
  settlement surface.
- No frontend or backend stage boundaries changed. No paid model/provider calls
  were made.
