## Contract delivered

- Added `novel_to_comic.panel_generation` as the panel lifecycle owner:
  `prepare_panel_prompt` / `prepare_panel_request`,
  `resolve_panel_references`, `compile_panel_request`,
  `estimate_panel_request`, and `submit_panel_request`.
- Panel draw, batch/retry draw, plain rerender, manual rerender, and
  instructed rerender now compile one `ProviderWireRequest` and freeze it
  before queued execution. Queued jobs consume only the frozen request.
- Prepared estimates expose the exact execution fingerprint. Unprepared
  estimates are explicitly `provisional`, make no preparation/model call, and
  do not expose an exact wire fingerprint.
- Panel cache matching requires `execution_fingerprint`; selected-byte/path-
  same changes invalidate while diagnostic-only changes do not.
- Added panel provenance schema version `1`, persisted beside successful and
  failed panel outputs. It records compiler/wire/frozen versions, request and
  execution identities, selected references/facets/digests/order, diagnostics,
  configured versus actual model identity, dimensions, provider result data,
  failure data, and a deterministic timestamp-independent record hash.
- Added queued-job completion/failure provenance callbacks that do not suppress
  usage settlement if metadata persistence fails.
- Added explicit Labs `production_equivalent` mode. It server-recompiles and
  validates the owned source panel, uses portable frozen wires, records the
  common provenance envelope in cell metadata, and applies experiment inputs
  as attributable compiled/execution identity changes. Existing experimental
  Labs provider paths remain explicit separate mode.
- Added panel scene-id validation on rerender and estimate routes and
  redaction of project paths in provenance diagnostics.
