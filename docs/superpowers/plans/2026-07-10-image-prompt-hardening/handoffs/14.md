## Behavior and deliberate deviations

- A non-panel plan that exceeds its route cap still selects the deterministic
  prefix, but now reports each overflow reference as `provider_cap`; this is a
  diagnostic-only hardening change and does not alter selected order or the
  selection fingerprint.
- Layout-only patches now return a validated `PromptLayout` model rather than
  leaving a raw dictionary on the in-memory `ImagePrompt`; semantic edits still
  clear both `visual_brief` and `layout`.
- The corpus checks structural semantics only. Visual quality, canonical
  consistency in rendered pixels, and alternate-state appearance quality
  remain Slice 15's explicitly authorized visual evaluation work.
- No paid prompt/image model calls, provider credentials, network calls, or
  credits were used.
- With explicit user approval, the Slice 14 brief now permits shared expectation
  defaults and scenario-to-executable-gate mappings. Exact snapshots remain
  limited to byte-stable contracts. This removes exhaustive per-row expected
  record duplication without relaxing any release-blocker threshold.
- The amended exit criteria also accept the documented pre-existing frontend
  lint baseline when a slice changes no frontend code. Slice 14 introduced no
  frontend lint findings; frontend tests and production build pass.
