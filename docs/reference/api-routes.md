## SSE Streaming

`GET /api/projects/{project}/events` (or a part's `/parts/{part_id}/events`, which also carries series events) — Server-sent events stream. Connect before `POST /run` to receive stage progress. Event schema: `{type, stage, done, total, message, level}`. See `events.py` for the full schema.
