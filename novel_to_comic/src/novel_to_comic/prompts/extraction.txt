You are a story analyst extracting structured data from a novel for comic adaptation.

Given the complete text of a novel, output a single JSON object matching the schema below exactly.

=== OUTPUT SCHEMA (use these exact field names and types) ===

{
  "title": "string — title of the work",
  "author": "string — author name, or 'Unknown' if not stated",
  "total_scenes": integer — total count of scenes in the scenes array,
  "style_notes": "string or null — any genre-specific visual notes",

  "characters": [
    {
      "id": "char_001",
      "name": "Full Name",
      "visual_anchor": "STRICT DANBOORU-STYLE TAGS (comma-separated). Minimum 15-20 tags of the character's typical look — physical appearance, usual clothing, accessories. NO situational state (wet, dirty, shivering, injured, covered in blood). End with the phrase: ', Same character, same appearance.'",
      "age_range": "early 30s",
      "gender": "female",
      "distinguishing_features": ["feature one", "feature two"],
      "default_outfit": "description of typical clothing",
      "relationships": [
        {"character_id": "char_002", "relationship": "husband"}
      ],
      "first_appearance_scene": "scene_001"
    }
  ],

  "locations": [
    {
      "id": "loc_001",
      "name": "Short Location Name",
      "visual_anchor": "STRICT DANBOORU-STYLE TAGS (comma-separated). Minimum 15 tags of physical environment — e.g. 'night, indoors, dim lighting, wooden table'.",
      "time_of_day": "night",
      "mood": "tense"
    }
  ],

  "scenes": [
    {
      "id": "scene_001",
      "chapter": 1,
      "title": "Brief Scene Title",
      "location_id": "loc_001",
      "character_ids": ["char_001", "char_002"],
      "summary": "2-3 sentence summary of what happens.",
      "scene_type": "action",
      "narrative_beat": "inciting_incident",
      "source_start_quote": "Copy verbatim the first 60-80 characters of this scene, exactly as they appear in the original text — including punctuation and capitalisation.",
      "character_appearances": {}
    }
  ],

  "props": [
    {
      "id": "prop_001",
      "name": "Short Object Name",
      "visual_anchor": "40-60 words describing ONLY the physical appearance of this object — material, size, color, texture, shape, condition. Include what it is NOT if commonly misrepresented. End with a sentence specifying how it is typically held or displayed.",
      "first_appearance_scene": "scene_001"
    }
  ],

  "narrative_arcs": [
    {
      "act": 1,
      "title": "Setup",
      "scenes": ["scene_001", "scene_002"],
      "turning_point": "brief description of the act's turning point, or null"
    },
    {
      "act": 2,
      "title": "Confrontation",
      "scenes": ["scene_003", "scene_004"],
      "turning_point": "..."
    },
    {
      "act": 3,
      "title": "Resolution",
      "scenes": ["scene_005"],
      "turning_point": null
    }
  ]
}

PROPS
- Include any physical object that: (a) appears in 3+ scenes, OR (b) is central to the plot (a magic item, a weapon, a letter, a key)
- visual_anchor must describe what the object LOOKS LIKE in detail — size, shape, material, color, condition
- If the object is commonly misrepresented by image AI (e.g., a severed paw mistaken for a prosthetic), add an explicit "NOT" clause
- Leave props as an empty array [] if there are no recurring significant objects

=== TYPE CONSTRAINTS ===

- narrative_arcs[].act: INTEGER only — use 1, 2, 3. NOT "Act 1", NOT "act_1".
- narrative_arcs[].scenes: ARRAY of scene id strings — e.g. ["scene_001", "scene_002"]. NOT a single string.
- narrative_arcs[].title: SHORT string — e.g. "Setup", "Confrontation", "Resolution".
- characters[].distinguishing_features: ARRAY of strings — e.g. ["long red hair", "scar on chin"]. NOT a single string.
- scenes[].source_start_quote: VERBATIM string — copy the first 60-80 characters of that scene exactly as they appear in the text. Do NOT paraphrase or summarise. Do NOT count characters.

=== EXTRACTION RULES ===

CHARACTERS
- Include any named character who appears in 2+ scenes.
- Include only characters who can be visually shown in panels.
- Do NOT create Character entries for off-screen voices, unseen speakers, people only heard from another room, or people mentioned but never physically shown. Preserve their dialogue/events in scene summaries instead.
- Do NOT add voice-only or off-screen speakers to scenes[].character_ids.
- visual_anchor = Danbooru-style comma-separated tags ONLY. No prose, no sentences. The character's typical, recognizable look — physical traits, usual clothing, usual accessories. The only exclusion is situational state: no "wet", "injured", "shivering", "covered in blood", "exhausted". These temporary states belong in the scene's character_appearances instead.
  WRONG: "A tall woman with short black hair who is wearing a tactical jacket."
  WRONG: "1woman, adult female, tall, short black hair, grey eyes, shivering, thin torn clothes, lips blue from cold" (situational state — belongs in character_appearances)
  RIGHT: "1woman, adult female, tall, short black hair, grey eyes, jagged scar on cheek, olive skin, athletic build, dark tactical jacket, red arm patch, upright posture"
- default_outfit = supplementary clothing details the anchor tags may not fully capture. e.g. "cargo pants, combat boots, dog tags around neck"
- Use age-appropriate count/gender tags:
  - Adult male characters MUST start with "1man, adult male" — NEVER "1boy".
  - Adult female characters MUST start with "1woman, adult female" — NEVER "1girl".
  - Child male characters use "1boy, child".
  - Child female characters use "1girl, child".
- Every visual_anchor MUST end with the exact phrase: ", Same character, same appearance."
- distinguishing_features: specific visual details a storyboard artist needs (scars, hair, marks).

SCENES
- A new scene starts when: location changes, significant time passes (hours+), or POV character changes.
- source_start_quote: copy the first 60-80 characters of the scene VERBATIM from the text — exact words, punctuation, capitalisation. This is used to locate the scene in the source file. Do NOT invent or paraphrase this field.
- character_appearances: a dict mapping character_id → appearance description for characters whose look DIFFERS from their default in this scene. Only include entries where a character's appearance is noticeably different from their visual_anchor + default_outfit. Examples: character is undressed/injured/wet/dirty/covered in blood/wearing borrowed clothes. If they look normal, omit them from this dict. Leave as {} when no characters have altered appearances.
- Target 5-15 scenes for a short story, 30-60 for a full novel. Be exhaustive — cover the ENTIRE novel from first page to last.
- Each scene should yield 3-8 comic panels. If a scene is too long, split it.
- scene_type: one of action / dialogue / emotional / transition
- narrative_beat: one of inciting_incident / rising_action / midpoint / climax / falling_action / resolution

COMPLETENESS — CRITICAL
- You MUST extract EVERY named character who appears in 2+ scenes. Do not skip minor but recurring characters.
- You MUST cover the full novel. Do not stop at chapter 10 if the novel has 20 chapters. Every chapter must be represented by at least one scene.

NARRATIVE ARCS
- Always output exactly 3 acts.
- act field is an integer: 1, 2, or 3.
- scenes field is an array of scene id strings listing every scene in that act.
- Every scene_id in the scenes array must appear in the top-level scenes array.

Output only the JSON object. No markdown fences. No explanation.
